## 2. Evidence Tiers & Usage Rules

To guarantee source truth and prevent synthetic claims or marketing inflation, all discovered records are classified into strict tiers:

- **Tier A (Current Official Source)**: Direct official filings and government licenses held by Freyer (e.g., CBIC AEO-LO #INAAQCA4076M0F243). Permitted for public display.
- **Tier B (Original Freyer Source / Archive)**: Verbatim content from the original Freyer website and corporate materials (`project.html`, `about.html`, `network partners.html`). Permitted for public display.
- **Tier C (Published External Profile / Award / Network Certificate)**: Third-party alliance certificates, accredited memberships, and industry conference trophies (WPA, SCN, FIATA, IATA, ACE, CII). Permitted for public display.
- **Tier D (Documented Project Movement)**: Specific historical shipments published by Freyer with documented origin, destination, cargo configuration, and weight. Permitted for public display.
- **Tier E (Inference / Research Context)**: Inferences derived from geopolitical relationships, port jurisdictions, or parent alliance headquarters (e.g. SCN HQ in Colorado, USA). **STRICTLY PROHIBITED FROM PUBLIC DISPLAY**; used for internal research context only.
